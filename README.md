# Crake: Efficient Privacy-Preserving Cycle Detection in Federated Graphs

This repository contains the implementation of Crake from the paper *Crake: Efficient Privacy-Preserving
Cycle Detection in Federated Graphs*.

## Repository layout

| Path | Contents |
|---|---|
| `CrisMPC/` | The CRiS-MPC framework that Crake builds on |
| `src/` | The Crake implementation |
| `dataset/` | The datasets used in the evaluation |
